HSiKAN · the Kinematic Regime Compass

A robot's kinematic structure is a signed graph: links are nodes, joints are signed edges (rotational + / translational −), and closed loops are cycles. HSiKAN reads only this structure and learns a per-arity weight vector αk — the regime compass. Parallel mechanisms make it spike (four-bar → k=4, Stewart/delta → k=6); serial chains leave it flat.
