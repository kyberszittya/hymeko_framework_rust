# Spikes toy — a non-abelian connection needs the spike to select walk order

**Created-at:** 2026-06-27 15:28 JST · **Author:** Aiko (Claude Code) for Dr. Csaba Hajdu
**Completes:** `docs/plans/2026-06-26-rotor-spikes-ablation/` (the rotor → spiral → spikes trilogy). Supervised,
deterministic (CLAUDE.md §3 strict carve-out).

## The claim

SO(2) (the rotor toy) is abelian — a walk's holonomy is order-independent, so spikes do nothing. Spikes earn
their keep on a **non-abelian** connection (SO(3)): the holonomy of a walk depends on the **order** edges are
traversed, and **spike timing selects the time-ordered walk**.

## The toy

Two non-commuting SO(3) edge rotations `R_a = R_x(θ)`, `R_b = R_y(θ)` (`R_aR_b ≠ R_bR_a` for θ≠0). Per sample a
source `v ∈ R³` and a **spike** `s ∈ {0,1}` choosing the order; target `y = (s ? R_aR_b : R_bR_a)·v`. Three
models: **spike_gated** (learns θ_a,θ_b, uses `s` to select the ordered product), **order_blind** (a full
learnable linear map of `v` that *ignores* the spike), **mlp** (flat `(v,s)` reference).

|---|---|---|---|---|
| 0.0 | 0.000 | **0.000** | 0.000 | — |
| 0.3 | 0.000 | 0.0013 | 0.000 | 1.3e6 |
| 0.6 | 0.000 | 0.020 | 0.001 | 2.0e7 |
| 0.9 | 0.000 | 0.091 | 0.001 | 9.1e7 |
| 1.2 | 0.000 | 0.242 | 0.001 | 2.4e8 |
| 1.5 | 0.000 | **0.448** | 0.001 | 4.5e8 |

### Reading

- **At θ=0 (commuting) the order-blind model fits perfectly** — order is irrelevant, no spike needed. The
  control passes.
- **As θ grows (non-abelian) order_blind's error rises monotonically with the commutator** (0 → 0.45). Without
  the spike it can only reach the *average* of the two orders → it is stuck at the order-dependent residual.
- **spike_gated ≈ 0 at every θ** — it uses the spike to select the order, so non-commutativity is no obstacle.
- The **mlp also fits** (≈0.001): given the spike `s` as input, even a flat net learns the conditional product.
  So the load-bearing point is **the spike information itself is necessary** — `order_blind` (no `s`) cannot
  represent the target once the connection is non-abelian; with `s`, both the structured `spike_gated` and the
  flat MLP can. An oracle test (spike_gated with the true angles reproduces the target to 1e-5) confirms the
  order convention is correct.

## Stronger version — a generalization win (varying connection + multi-edge walks)

The basic toy shows the spike *information* is necessary (order-blind fails) but the MLP also fit it
(representability). The stronger version (`--walks`, `run_spike_walks`) makes it a *generalization* contest:
2 walks, each a length-L chain of SO(3) edge rotations about **cycling axes** (consecutive edges non-commuting),
the **connection (edge angles) varies per sample**, a spike selects the walk, target = the selected walk's
holonomy · v. **spike_gated** composes the rotations along the spike-selected walk (E learnable gains); the
**flat MLP** gets `(θ, onehot(s), v)`.

| walk length L | spike_gated | flat MLP |
|---|---|---|
| 1 | 0.000 | 0.010 |
| 2 | 0.000 | 0.056 |
| 3 | 0.000 | 0.170 |
| 4 | 0.000 | **0.302** |

**spike_gated stays ~0 at every L; the flat MLP degrades monotonically** with composition depth — it cannot
learn the L-fold conditional non-commuting product. This is a **generalization** advantage (the same signature
as the chain probe), not the basic toy's mere representability: with the walk structure + spike selection +
rotation form, the model composes the holonomy and generalizes; the flat net does not. An oracle test
(WalkSpikeGated at unit gain reproduces the target to 1e-5 for L=1..4) confirms the batched composition is
correct. Figure: `reports/spike_probe/spike_walks.png`.

## The trilogy, complete

| toy | group | shows |
|---|---|---|
| rotor (`rotor_probe`) | SO(2) | rotor = connection; signed Z₂ sees only the holonomy's sign (sin²Φ) |
| spiral (`spiral_probe`) | SO(2) | the spiral collects rotor-transport along walks; the plain highway carries none of it |

Together: signed graph → **rotor** connection (continuous holonomy) → **spiral** collection along walks →
**spike** timing (order selection when non-abelian). That is the gauge stack the HSiKAN line is built toward.
