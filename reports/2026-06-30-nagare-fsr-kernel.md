# Nagare FSR Kernel Report

Created-at: 2026-06-30 16:09 JST

## Summary

Implemented the Fiber-Spike-Rotor path for Nagare as closed-form Rust kernels:
quaternion rotor primitives in `hymeko_clifford`, `cayley_rotor`,
`signed_scatter`, and a composed `FsrMixer` in `hymeko_nagare`. The FSR path
uses fixed top-k indices and gate weights, then backpropagates analytically
through output linear, signed scatter, Cayley rotor, per-source value
accumulation, and input value linear.

The PyTorch golden fixture was generated with `uv run --group ml` using Torch
2.12.0+cu132, seed 1234, dims `(hidden=6, batch=1, seq_len=4, n_blocks=2,
max_seq_len=4, k=2)`. It is stored as a flat std-parseable text fixture under
`docs/plans/2026-06-30-nagare-fsr-kernel-codex/fixtures/`.

## Performance

No production benchmark was run; this was a kernel-correctness implementation.
The parity fixture is tiny and the full `cargo test -p hymeko_nagare` completed
in seconds with negligible memory relative to the 16 GB cap. Kernels are
single-threaded for the new FSR pieces and use ordered per-source/per-offset
accumulation; no atomics, globals, env flags, `unsafe`, or mutable statics were
introduced.
