# HSiKAN — architecture diagrams

Explanatory assets for *how HSiKAN works*, generated by
[`hymeko_neuro/demos/make_hsikan_animation.py`](../../hymeko_neuro/demos/make_hsikan_animation.py)
(GIFs) and the Mermaid flowchart.

| File | What it shows |
|---|---|
| `hsikan_forward.gif` | **Dataflow** view: signed graph → query edge → FIR (cycles/walks per arity) → HSiKAN-CR spline shell → **αₖ regime mix** → CPML sign. The αₖ bars are the **real learned regime** from `checkpoints/hsikan/bitcoin_otc_optuna_best.pt`. |
| `hsikan_neurons.gif` | **Neuron** view: a SignedKAN network (5→4→2) with a learnable **spline activation φ on every edge** (the KAN signature), signed green/red, a forward pulse sweeping layer by layer. |
| `hsikan_flowchart.mmd` / `.svg` | The most important steps as a flowchart (Mermaid source + rendered SVG). |

## Regenerate
```powershell
# GIFs (real αₖ needs the OTC checkpoint; pass --checkpoint "" for an illustrative regime)
PYTHONPATH=. .venv/Scripts/python.exe -m hymeko_neuro.demos.make_hsikan_animation `
    --mode both --out architecture/hsikan
```
The Mermaid SVG was rendered from `hsikan_flowchart.mmd`; re-render with any
Mermaid tool (`mmdc -i hsikan_flowchart.mmd -o hsikan_flowchart.svg`).

## Honest notes
- The GIFs are **schematic**: the graph, spline, and neuron glyphs illustrate the
  mechanism. The only real numbers are the αₖ bars (from the checkpoint).
- KAN places the learnable activation **on the edge** (φ), not the neuron; each
  neuron just sums. HSiKAN's inner SignedKAN is exactly this, with signed edges
  and Catmull–Rom spline bases.
